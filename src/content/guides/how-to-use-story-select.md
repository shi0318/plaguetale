**Story Select** is the cleanup tool after the credits, not a pause menu in Chapter III. Finish the story. Then replay the chapter whose Charm or Artefact you skipped.

The longer notes are on [Story Select cleanup](/story-select-cleanup/). This page is the order, so the two pages do not fight.

## Order

1. Install the October 6 bug-fix update if a chapter blocker stopped the credits. [October 6](/resonance-plague-tale-legacy-october-6-update/).
2. Watch the credits. Chapter XIV's book interaction is a retest if it was unusable. Do that before you hunt a chapter list.
3. Open Story Select and load the chapter, not a new file.
4. Sweep the side room you marked. Blades, Charms, and Artefacts are separate counters. [Collectibles](/collectibles/).

If a guide says every Resonance Point can be mopped up the same way, check that claim against the chapter you are in. Do not assume the menu grants a point you never triggered.
