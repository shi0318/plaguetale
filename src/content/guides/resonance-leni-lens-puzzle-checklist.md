If you are stuck at the **Chapter III lens interaction with Leni**, check the game build and retest the interaction before replaying the whole chapter. The October 6 bug-fix notes say that a Leni interaction which could not be triggered was fixed. That is useful for players who previously reached the room and got no response, but it is not a printed walkthrough of the room’s beam path.

This guide focuses on the practical question: how do you tell whether you are testing the fixed interaction? It separates the known trigger issue from the puzzle steps the available patch information does not describe. Follow prompts shown in your current build and avoid importing a made-up order from a generic light-puzzle guide.

## What is confirmed about the issue

The reported problem is narrow: in Chapter III, an interaction involving Leni and her lens could fail to trigger. The October 6 bug-fix update lists that issue as fixed. It does not specify a lens sequence, a numbered set of mirrors, a reward, or exact controls. A guide that supplies those details without observing them in the retail game is guessing.

That difference matters. When an interaction does not begin, there is no active puzzle state to solve. Repeating beam moves or searching every corridor will not address a trigger that never fired. First verify the build and the room. Only after Leni’s interaction starts should you treat the visible puzzle as the next step.

The Minoan sphere is part of the game’s light-puzzle vocabulary, and the store description says Sophia uses the stolen sphere to manipulate light. The lens issue is a separate reported interaction with Leni. Do not assume that every sphere puzzle uses the same room layout or that the patch note defines how this specific scene is solved.

## Retest in a controlled order

Use this sequence to avoid wasting a chapter replay:

1. **Install the October 6 update or a later build.** The listed fix cannot help an older installation.
2. **Load a save in Chapter III or just before the lens room.** Confirm the chapter label before you spend time retracing a route.
3. **Approach the interaction again.** Use the visible in-game prompt and let the current scene play far enough to establish whether it triggered.
4. **If it starts, follow what the game presents.** Read the room, visible light, and on-screen prompt rather than relying on an old video recorded during the failure.
5. **If it still does not start, verify the installed build and reload once.** Note exactly what the game does; repeated retries on an unpatched build do not test the fix.

The key result is a simple yes or no: does the Leni interaction now begin? If yes, continue with the puzzle instructions the game shows. If no, check the build again before restarting the chapter. That one controlled check helps separate an old trigger failure from a different issue.

## How to read the room after it triggers

Once the interaction begins, stop treating the room as a bug report and inspect what is visible. Look for the active light source, the surfaces or devices the game highlights, and any response to your current action. Change one thing at a time so you can tell what caused the scene to advance. If nothing responds, return to the prompt and verify that you are interacting with the intended object rather than a nearby prop.

Use the game's own feedback as the authority. If a beam moves, note which object changed. If the scene advances after an interaction, note that action before trying another. If the game gives no prompt or visible response, do not invent a hidden sequence and claim it is the official solution. The available bug-fix detail confirms the interaction was repaired; it does not publish a room-by-room solution.

This method is useful for light puzzles in general, but the order should come from the current room. A sphere puzzle, a lens interaction, and a combat encounter can all occupy the same chapter without sharing controls or objectives. Read the room before switching to the sling, sphere, or melee tools.

## If the retest does not work

Check the basics in this order:

- Confirm the game updated successfully, rather than assuming an update download finished.
- Confirm the save is in Chapter III and near the Leni interaction described by the fix.
- Reload once on the updated build and try the interaction again.
- Record whether the prompt appears, whether the interaction animation starts, and what happens immediately afterward.
- If the same trigger still fails, use the game's support or community reporting path with the build and chapter details.

Do not delete a save or restart the full campaign based on this issue alone. The patch note does not say that an old save is invalid, and it does not promise that replaying from the beginning repairs every case. Start with the least disruptive test: correct build, correct room, one reload, one interaction attempt.

## Do not mix this up with other chapter fixes

The October 6 update lists several distinct problems across the campaign. Chapter IX has a crouch issue after backtracking. Chapter XIII has a progression/save issue. Chapter XIV has a book interaction after the credits. The update also addresses other combat, stability, and equipment behavior. Those notes do not describe the Chapter III lens interaction.

If your problem is that Sophia cannot crouch in a later palace area, you are not troubleshooting Leni’s lens. If the issue is a post-credit book, use the Chapter XIV note. Identifying the chapter and interaction prevents a fix for one failure from becoming misleading advice for another.

## Common time-wasters

**Replaying before updating.** The fix applies to the updated game. Reproducing the old failure on an earlier build tells you nothing about the new one.

**Searching the room before the trigger starts.** A puzzle cannot advance if the scripted interaction has not begun. Verify the interaction first.

**Following a generic beam order.** Light puzzles can share a theme without sharing a solution. Use the objects and prompts in this room.

**Changing several things at once.** If you move multiple objects or leave and return, you lose the ability to tell which action made the scene respond.

**Calling a failed trigger a missing collectible.** The official bug line is about an interaction. It does not mention an artifact, blade, charm, or achievement reward.
