The October 6, 2026 **Bug Fixes update** is the first thing to install if Resonance: A Plague Tale Legacy hitches when approaching a new Nemesis Area, forgets an image setting, or stops a chapter from advancing. Later coverage repeats this patch; it does not replace it. If you are judging stutter, a stuck interaction, or a review complaint, make sure this build is installed first.

## What the update changes

The published notes name support for **21:9**, reduced stutter while approaching new **Nemesis Areas**, PSSR settings that now save on PS5, and a fix for AMD Anti-Lag not working when Frame Generation is disabled. They also list crash and progression fixes, combat-system improvements, animation fixes for multiple cutscenes, and accessibility, audio, and localization work.

| Area | Published change | What to check in your save |
| --- | --- | --- |
| Image options | PSSR settings now save correctly on PS5; 21:9 support is fixed; AMD Anti-Lag works when Frame Generation is disabled | Re-open the display menu and confirm the option stays active after a restart |
| Traversal | Stutter when approaching new Nemesis Areas is reduced | Retry the same area boundary after installing |
| Stability and progress | Numerous crash fixes and fixes for progression-blocking issues | Load the affected save and try the named step before replaying the chapter |
| Combat and animation | Combat-system improvements and animation fixes for multiple cutscenes | Revisit the encounter or scene that misbehaved |
| Other fixes | Accessibility, audio, and localization fixes | Confirm subtitle, audio, and language options after updating |

The notes do not publish a frame-rate target, per-GPU benchmarks, or a promise that every hitch on every PC is gone. The headline performance change is specific: less stutter on the approach to new Nemesis Areas.

## Chapter fixes: III, IX, XIII and XIV

Four chapter blockers are named in the same update. Each could make a chapter look unfinishable when the objective was still valid.

| Chapter | Fixed problem | What to try |
| --- | --- | --- |
| III | Leni's lens interaction could not be triggered | Return to the lens scene and look for the interaction prompt |
| IX | Crouching could fail in the petrified area after palace backtracking | Backtrack through the palace route and try crouch in that area |
| XIII | Progression could fail after an earlier corrupted squeeze-through state | Load the affected save and confirm the next step saves |
| XIV | The book could become unusable after the credits | Reopen the book interaction after the credits sequence |

The update also improves **Nemesis navigation**, NPC behaviour in multiple chapters, and several blocking object interactions. Those matter when an enemy or an object appears to stop the story even though the objective is still on screen.

## Is Leni's Chapter III lens fixed?

Yes — the notes specifically fix the case where Leni's lens interaction in **Chapter III** could not be triggered. After updating, load the affected save and return to the same scene: the prompt should be available in the same story context without starting a new file.

The fix does not add a new button mapping, a hidden item, or a different puzzle solution. If the scene still shows no prompt, confirm the game restarted into the updated build and that you are standing at the same object and story state that failed before. The step-by-step version lives on the [Leni lens puzzle checklist](/resonance-leni-lens-puzzle-checklist/) and the [Chapter 3 lens guide](/resonance-leni-lens-puzzle-checklist/).

## Check your save before restarting

Do not start a new file first. A safe order:

1. Let Steam finish the update, then restart the game so it runs the current build. Note your platform and display mode, so a performance problem is not confused with a story blocker.
2. Load the save that showed the problem and try the named step in its original context — Chapter III's lens, Chapter IX's petrified-area crouch, or Chapter XIII's save step.
3. If the chapter now advances, make a fresh manual save at the next stable point. Keep the old file until the chapter is confirmed clear.
4. If the interaction still fails, separate it from Nemesis navigation, collision, or an input-setting problem before you change anything else.

For Chapter IX specifically, the [Chapter IX backtracking and crouch guide](/resonance-chapter-nine-backtracking-plan/) goes into the palace route. For the Chapter XIV book, see [the book after the credits](/resonance-book-after-credits/).

## If the Nemesis approach still hitches

1. Confirm the update finished and restart the game.
2. Return to the same Nemesis Area approach where the hitch happened. Do not compare a different chapter or camera angle.
3. Re-open display options and check PSSR, Frame Generation, and the aspect ratio rather than trusting an earlier menu selection.
4. If it still stutters, separate the remaining traversal hitch from a crash, a stuck objective, or a generally low frame rate. Those need different settings checks and different bug reports.

Change one setting at a time. If you switch several at once, you will not know which one helped.
