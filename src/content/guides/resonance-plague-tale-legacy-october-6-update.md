The October 6, 2026 **Bug Fixes update** is the first thing to install if **Resonance: A Plague Tale Legacy** hitches when approaching a new Nemesis Area, forgets an image setting, or drops a chapter after a crash. The update names support for **21:9**, reduced area-transition stutter, a fix for AMD Anti-Lag not working when Frame Generation is disabled, stability and progression fixes, and additional combat, accessibility, animation, audio, and localization work.

The headline performance issue is specific: this update reduces stutter while approaching new **Nemesis Areas**. It does not publish a frame-rate guarantee or claim every hitch on every PC is gone.

## What the October 6 update changes

| Area | Published change | What to check in your save |
| --- | --- | --- |
| Image options | PSSR settings now save correctly on PS5; 21:9 support is fixed; AMD Anti-Lag works when Frame Generation is disabled | Re-open the display menu and confirm the selected option remains active after restarting |
| Traversal | Stutter when approaching new Nemesis Areas is reduced | Retry the same area boundary after installing the update |
| Stability and progress | Numerous crash fixes and fixes for progression-blocking issues | Load the affected save and test the named step before replaying the full chapter |
| Combat and animation | Combat-system improvements and animation fixes for multiple cutscenes | Revisit the relevant encounter or scene and check whether the specific issue is gone |
| Other fixes | Accessibility, audio, and localization fixes | Confirm subtitle, audio, and language options after updating |

The patch notes do not publish an itemised benchmark for each GPU, exact frame-time results, a complete bug list, or a guarantee that every player-reported issue is solved. Use a repeatable test: same save, same area transition, same display mode, and the updated build.

## If the Nemesis approach still hitches

1. Let Steam finish installing the update, then restart the game so it is running the current build.
2. Return to the same Nemesis Area approach where the hitch occurred. Do not compare a different chapter or camera angle.
3. Re-open display options and check PSSR, Frame Generation, and the aspect ratio rather than trusting a previous menu selection.
4. If the game still stutters, separate the remaining traversal hitch from a crash, a stuck objective, or general low frame rate. Those need different reports and settings checks.
