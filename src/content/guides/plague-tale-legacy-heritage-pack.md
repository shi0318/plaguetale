The Heritage Pack is Steam app 3837640, listed at $3.99 next to the $49.99 base game. It is a pack. It is not a chapter, not a rat-swarm toggle, and not the PSSR fix. The bugfix update is free. Install that whether or not you buy the pack.

Buy the pack if you want the extra cosmetic set it advertises and you already like the game. Do not buy it to lengthen a 10-hour campaign. The campaign length is the campaign. A sling skin will not add a fourteenth chapter.

The base game is the one the Very Positive score is about. If you are waiting on a sale, wait on the base game. The pack can sit.
