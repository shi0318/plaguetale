## Minimum PC requirements

| Component | Official minimum |
| --- | --- |
| Operating system | Windows 10/11 64-bit |
| Processor | AMD Ryzen 3 3100 or Intel Core i3-12100 |
| Memory | 16 GB RAM |
| Graphics | AMD Radeon RX 5500 XT or NVIDIA GeForce GTX 1060 with 6 GB VRAM |
| Storage | 75 GB available space |
| Drive | SSD required |
| Target listed by Steam | 1080p, Low settings, 30 FPS |

## Technical requirements that are easy to miss

Steam also lists **DirectX 12.1**, **Shader Model 6.6**, and a **4-core/8-thread CPU** requirement. Those details matter if a PC appears to meet the named CPU and GPU models but has an older platform or a configuration that does not support the required graphics feature level.

The official listing also describes DLSS 4.5 with Dynamic Multi Frame Generation and Super Resolution, together with ray-traced Lumen and Ray Reconstruction. Those are launch-technology notes; they should not be used to claim that a below-minimum GPU will run the game.

## What this page does not claim

- The listed storage is required available space, not necessarily the compressed download size.
- The 30 FPS and 60 FPS figures are the official target labels, not an independent test of every PC.
- The requirements do not establish console performance modes, preload timing, or a universal graphics preset for every driver version.

Before launch, compare your hardware with the tables above and keep the official Steam page bookmarked. After launch, this page can add measured settings only when the test hardware, driver, build, resolution, and preset are recorded.
