Story Select is in the shipped game. Player reports put it next to the chapter count: you finish, you notice a collectible or an achievement, you reopen the chapter. You do not start a new file because a bird skull was on a terrace.

## What Select does not refund

Skill points lost on death stay lost, in the reports that describe that split. Collectibles that already persisted do not need Select. Open Select for the thing that is chapter-locked, not for a currency you can still earn.

If a chapter hitch or a PSSR stutter ruined a room, patch first, then Select into that chapter. Replaying the coast on a broken image setting is how a short game becomes a long evening.

The [missable achievement list](/missable-achievements-guide/) is the checklist. Select is the button.
