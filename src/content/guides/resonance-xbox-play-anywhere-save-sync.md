If you started **Resonance: A Plague Tale Legacy** on Xbox Series X|S, you can continue the same campaign on the **Xbox app version for Windows**. Use the same Xbox/Microsoft account on both devices, let the game save on the device you last played, and let the next device finish syncing before selecting Continue. Focus Entertainment confirms the game supports Xbox Play Anywhere, and Microsoft lists Xbox cloud saves on the product page. ## Check which copy you have before installing

Xbox Play Anywhere covers eligible digital purchases through Xbox or Microsoft’s Windows storefront. Microsoft says the same account can download the game on Xbox and Windows and carry saves, supported add-ons and achievements across those devices. Sign in with the account that played the campaign, even if another profile on the console can also launch the game. Access through a shared console and the identity attached to a save are separate checks. [Microsoft’s Xbox Play Anywhere FAQ](https://www.xbox.com/en-US/games/xbox-play-anywhere)

- **You bought the Xbox digital edition.** Look for the title in My Games & Apps on Xbox and in My Library in the Windows Xbox app. The Xbox listing carries the Play Anywhere badge. Verify that you are signed into the account that holds the digital purchase before trying another checkout.
- **You played through Game Pass.** Focus and Xbox announced that access at launch. Check the current listing while signed in for the plan, region and device you want to use. On November 26 the US Xbox listing showed PC-only and Ultimate under its subscriptions, with cloud play included with Ultimate. Cloud play and the PC or console install are separate access checks. A streaming button does not by itself confirm a PC installation entitlement. [Xbox Wire Game Pass announcement](https://news.xbox.com/en-us/2026/08/18/xbox-game-pass-august-2026-wave-2/) · [Xbox product page](https://www.xbox.com/en-us/games/store/resonance-a-plague-tale-legacy/9ppbncxp0096)
- **You bought Steam, Epic or PS5.** Open the corresponding library and verify which edition is installed before trying to load a campaign. Play Anywhere is the Microsoft service, so its documentation establishes Xbox and Windows Xbox-app syncing. Focus lists Steam, Epic and PS5 as separate releases and does not document a transfer from those versions into the Xbox save. See the [Steam features guide](/steam-features-controller-cloud/) for the separate Steam Cloud workflow.

The Windows Xbox app can make an owned title available even when the computer cannot run it comfortably. Check the product’s PC system requirements for the device you’re moving to. If you use a supported Windows handheld, verify the installation and storage on that device before relying on it for a trip. [Xbox Play Anywhere](https://www.xbox.com/en-US/games/xbox-play-anywhere) · [PC requirements](/pc-system-requirements/)

## Move one checkpoint from Xbox to Windows

1. **Start on the device with the newest progress.** Load the intended campaign and confirm the chapter and the latest progress you can identify. If you are somewhere between checkpoints, play until the game saves. Note the chapter, location and one detail such as a puzzle state or a recent pickup. This gives you something to compare with the receiving device.
2. **Close the game in the normal way.** Let a visible save operation finish first. Keep the source device online while you end the session. On Xbox, fully quit the running game if you need a clean test, instead of leaving the session suspended while you open the Windows copy. Microsoft says the same game can be active on one device at a time. [Microsoft’s Xbox Play Anywhere FAQ](https://www.xbox.com/en-US/games/xbox-play-anywhere)
3. **Open the Xbox app version on Windows.** Check the Xbox profile shown in the app and sign in with the same account you used on the console. Launch the Microsoft copy from its library entry. Let any save-sync prompt finish. If the menu already offers Continue, use it and compare the loaded checkpoint with the one you wrote down.
4. **Verify before making new progress.** Confirm the game resumes on the expected chapter and near the same location. Check one distinguishing detail before finishing an encounter or opening a new campaign. Once the expected state appears, reach another normal checkpoint to test the opposite direction later.

The same sequence works in reverse. Start on the Windows Xbox app copy that has the newer checkpoint, close it after saving, then open the Xbox copy with the same account. A resumed session tells you which checkpoint the receiving build loaded. Keep an earlier checkpoint if the game offers one while you confirm both devices show the same campaign.

## If Windows only offers New Game

First distinguish **missing game access** from **missing progress**. If the Xbox app offers Buy instead of Install or Play, verify the signed-in profile and its purchase or current subscription access. A save belongs to the profile that made it. Resolving ownership on the wrong profile will still leave you looking at the wrong campaign.

If the correct edition launches but shows no Continue option, close it without starting a replacement campaign. Return to the other device and verify the original save still opens. Check that both installations have finished updating and both devices are online. Try one clean handoff with the original device closed before trying additional changes. You can identify the last update the publisher described in the [October bug-fix guide](/resonance-plague-tale-legacy-october-6-update/).

If a conflict prompt offers two copies, read its device or timestamp details. Compare those details with the last known good checkpoint. When neither choice can be matched to the progress you want, preserve the original device’s save and capture the message before accepting a choice or clearing stored data. For a repeatable failure, record the two device types, the date and chapter, the edition and the exact message for Xbox Support. [Xbox cloud saves FAQ](https://support.xbox.com/en-US/help/games-apps/game-setup-and-play/cloud-game-saves-faq)

## If the right chapter appears with older progress

Check what was actually saved on the first device. Being in the right chapter does not prove the last encounter or pickup reached the next checkpoint. A save that loads correctly at an older checkpoint calls for a comparison on the source device. Go back there, load the campaign, and compare the same landmark. If both devices load the older state, investigate where the game recorded progress before making more account or cloud changes. For chapter replay and collectible-state questions, use the [Story Select cleanup guide](/story-select-cleanup/).

A successful handoff is simple to recognize. The same account opens the same chapter, checkpoint and recent campaign state on both Microsoft builds. If you decide to play a separate Steam, Epic or PlayStation copy, treat that as a new storefront decision and confirm any save-transfer feature before counting on it. The [platforms guide](/platforms/) lists the other versions.
